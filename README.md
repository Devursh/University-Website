# University-Website

## Overview

This project is a university-themed website designed to showcase a university's programs, campus, and student experience. The goal was to create a clean, organized, and user-friendly website while practicing front-end web development and responsive design.

## Features

* University homepage and navigation
* Information about university programs and opportunities
* Organized sections for different types of information
* Responsive layout for different screen sizes
* Interactive navigation and buttons
* Clean and consistent visual design

## Technologies Used

* HTML
* CSS
* JavaScript

## What I Learned

This project helped me improve my understanding of front-end web development, particularly structuring webpages with HTML, styling layouts with CSS, and adding interactivity with JavaScript. I also gained more experience thinking about how users navigate a website and how information should be organized.
